Based on the uploaded IOIS index structure, rebuilt as a single-page experience.
Includes Home, Services, 7 Plans, fixed referral examples, Learning, Updates, Registration, Referral link, Help, FAQ and Login UI.

Final reward examples:
₹10→₹7, ₹49→₹35, ₹99→₹70, ₹199→₹140, ₹299→₹210, ₹499→₹350, ₹999→₹700.

Vercel Environment Variables:
TELEGRAM_BOT_TOKEN=<current token>
TELEGRAM_CHAT_ID=-1004430484996

Do not place the Telegram bot token in GitHub.
Registration sends details/photo to Telegram.

Important: secure real login/password accounts require persistent authentication/database. The included login endpoint intentionally refuses insecure password storage rather than pretending a static site has real authentication.
